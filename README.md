# everycallcovered.com

Static "launching soon" landing page for Every Call Covered, hosted on GitHub Pages.

- `index.html`: the page (one file, inline CSS, no JavaScript, no forms, no tracking).
- `CNAME`: the custom domain GitHub Pages serves.
- DNS for everycallcovered.com is managed at Wix (registrar); it points at GitHub Pages.

The product itself lives in Worlds2025/pro-appliance-voice. This repo is only the public landing page.
